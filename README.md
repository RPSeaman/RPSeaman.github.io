## Run Locally

### Prerequisites
- Node.js (v14 or higher)

### Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RPSeaman/RPSeaman.github.io.git
   cd RPSeaman.github.io
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
